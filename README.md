# 🎓 เว็บไซต์ประชาสัมพันธ์และรับสมัครนักเรียน นักศึกษา วิทยาลัยเทคนิคชัยภูมิ

> 🔵⚪ อดทน ขยัน มีระเบียบวินัย คุณธรรมนำวิชาชีพ — สีประจำวิทยาลัยเทคนิคชัยภูมิ

เว็บไซต์ต้นแบบ (prototype) สำหรับประชาสัมพันธ์และรับสมัครนักเรียน นักศึกษา วิทยาลัยเทคนิคชัยภูมิ
พร้อมผู้ช่วย AI **"น้องเทคนิค" 🤖** ที่คอยตอบคำถามผู้สนใจสมัครเรียนแบบเรียลไทม์ (streaming)
ตลอด 24 ชั่วโมง

## 📖 ที่มาที่ไปของโปรเจกต์

จัดทำโดย **แผนกวิชาเทคโนโลยีสารสนเทศ วิทยาลัยเทคนิคชัยภูมิ** เพื่อส่งเข้าประกวด
**🏆 สิ่งประดิษฐ์ของคนรุ่นใหม่ ประจำปีการศึกษา 2569** ประเภทผลงานหลัก กลุ่ม **ปัญญาประดิษฐ์ (AI)**

## 🧰 เทคโนโลยีที่ใช้

- ⚛️ **[Next.js 16](https://nextjs.org)** (App Router + Turbopack) — เฟรมเวิร์กหลักของเว็บไซต์
- 🔷 **TypeScript** — เขียนโค้ดปลอดภัย ตรวจชนิดข้อมูลก่อนรัน
- 🎨 **Tailwind CSS v4** — จัดหน้าตาเว็บโทนน้ำเงิน-ขาวทันสมัย
- 🧠 **[Ollama](https://ollama.com/)** — รันโมเดล AI (Llama 3.2) บนเครื่องเอง เป็นสมองของแชทบอท "น้องเทคนิค" **ฟรี ไม่มีค่าใช้จ่ายต่อการเรียกใช้**
- 🐬 **[MariaDB](https://mariadb.org/)** — ฐานข้อมูลเก็บใบสมัครเรียน
- 🐳 **Docker / Docker Compose** — รันเว็บไซต์ + Ollama + MariaDB เป็น container ได้ในคำสั่งเดียว

## ℹ️ ที่มาของข้อมูลวิทยาลัย

ข้อมูลวิทยาลัยในเว็บไซต์นี้อ้างอิงจากเว็บไซต์จริง **[www.ccollege.ac.th](https://www.ccollege.ac.th)**
(สืบค้นเมื่อ 25 ก.ย. 2569) ได้แก่ ชื่อ ที่อยู่ เบอร์โทร อีเมล โซเชียลมีเดีย ประวัติ สาขาวิชา และข่าวประชาสัมพันธ์ล่าสุด

⚠️ ส่วน **รอบรับสมัคร / คุณสมบัติ / เอกสารการสมัคร** เว็บไซต์จริงยังไม่ได้ประกาศรายละเอียดสำหรับปีการศึกษา 2569
จึงใช้แนวทางทั่วไปตามระเบียบสำนักงานคณะกรรมการการอาชีวศึกษา (สอศ.) แทนไปก่อน
(มีข้อความแจ้งเตือน ℹ️ สีฟ้ากำกับไว้บนหน้า "การรับสมัคร" ของเว็บไซต์)

**แนะนำให้อาจารย์ตรวจทานความถูกต้องอีกครั้งก่อนใช้งานจริง** โดยเฉพาะปฏิทินรับสมัครที่วิทยาลัยจะประกาศภายหลัง

## 🚀 เริ่มต้นใช้งาน

แชทบอทใช้ **Ollama** รันโมเดล AI บนเครื่องเอง **ไม่ต้องมี API key ไม่มีค่าใช้จ่าย** 🎉
ฐานข้อมูลใบสมัครใช้ **MariaDB** เลือกได้ 2 วิธี ตามความสะดวก 👇

### วิธีที่ 1 — รันด้วย 🐳 Docker (แนะนำ ง่ายที่สุด)

ต้องติดตั้ง [Docker Desktop](https://www.docker.com/products/docker-desktop/) ก่อน จากนั้น:

```bash
cp .env.example .env.local   # ตั้งรหัสผ่านต่าง ๆ เอง หรือใช้ค่าเริ่มต้นไปก่อนได้
docker compose up --build -d
```

คำสั่งนี้จะรันเว็บไซต์ + Ollama + MariaDB ให้อัตโนมัติทั้งหมด พร้อมดาวน์โหลดโมเดล `llama3.2:3b` (~2GB)
ให้เองในการรันครั้งแรก (ใช้เวลาสักพักตามความเร็วอินเทอร์เน็ต) เปิดเบราว์เซอร์ไปที่
[http://localhost:3000](http://localhost:3000)

```bash
docker compose logs -f ollama  # ดูความคืบหน้าการดาวน์โหลดโมเดล
docker compose logs -f web     # ดู log ฝั่งเว็บไซต์แบบเรียลไทม์
docker compose down            # หยุดและลบ container (ข้อมูลใน MariaDB ยังอยู่ใน volume)
```

### วิธีที่ 2 — รันบนเครื่องโดยตรง (npm)

**1. ติดตั้ง [Ollama](https://ollama.com/download) แล้วดาวน์โหลดโมเดล**

```bash
ollama pull llama3.2:3b
```

**2. รัน MariaDB** (ใช้ Docker รันแค่ตัวฐานข้อมูลก็ได้ ไม่ต้องรันทั้งสต็อก)

```bash
docker compose up -d mariadb
```

**3. ติดตั้ง dependencies ของเว็บไซต์**

```bash
npm install
cp .env.example .env.local   # ค่าเริ่มต้นใช้ได้เลย ไม่ต้องแก้อะไร
```

**4. รันเซิร์ฟเวอร์สำหรับพัฒนา/สาธิต**

```bash
npm run dev
```

เปิดเบราว์เซอร์ไปที่ [http://localhost:3000](http://localhost:3000) 🎉

> 💻 **ข้อควรรู้เรื่องสเปกเครื่อง:** โมเดล `llama3.2:3b` (ค่าเริ่มต้น) เลือกมาให้รันได้บน CPU ทั่วไปโดยไม่ต้องมีการ์ดจอ
> แต่คุณภาพ/ความเป็นธรรมชาติของภาษาไทยจะไม่เท่า Claude หรือโมเดลขนาดใหญ่ หากเครื่องแรงพอ (มีการ์ดจอ หรือ RAM เยอะ)
> สามารถเปลี่ยนไปใช้โมเดลที่ใหญ่ขึ้นได้ เช่น `llama3.1:8b` หรือ `qwen2.5:7b` โดยแก้ `OLLAMA_MODEL` ใน `.env.local`
> (หรือใน `docker-compose.yml`) แล้วรัน `ollama pull <ชื่อโมเดล>` ใหม่

## 🐬 ฐานข้อมูลใบสมัคร (MariaDB)

ใบสมัครที่นักเรียนกรอกที่หน้า `/admission/apply` จะถูกบันทึกลง MariaDB โดยอัตโนมัติ
ดูรายชื่อทั้งหมดได้ที่หน้า **[`/admin`](http://localhost:3000/admin)** (ต้องใส่รหัสผ่านจาก `ADMIN_PASSWORD` ใน `.env.local`)

### เปิดดูฐานข้อมูลด้วย DBeaver (หรือโปรแกรมจัดการฐานข้อมูลอื่น)

MariaDB เป็นฐานข้อมูลแบบเซิร์ฟเวอร์ (ต่างจากไฟล์เดี่ยวแบบ SQLite) เชื่อมต่อผ่านเครือข่ายด้วยค่าต่อไปนี้
(ดูค่าจริงได้ในไฟล์ `.env.local` ของอาจารย์):

| ช่อง | ค่า |
|---|---|
| Host | `localhost` |
| Port | `3306` |
| Database | ค่าจาก `MARIADB_DATABASE` |
| Username | ค่าจาก `MARIADB_USER` |
| Password | ค่าจาก `MARIADB_PASSWORD` |

ใน DBeaver: **New Database Connection → MariaDB** → กรอกค่าด้านบน → **Test Connection** → **Finish**
(ต้อง `docker compose up` ให้ container `mariadb` รันอยู่ก่อน ถึงจะเชื่อมต่อได้)

เปิดไฟล์ [`lib/college-data.ts`](./lib/college-data.ts) แล้วแก้ไขส่วนที่ต้องการ:

ไม่ต้องแก้โค้ดส่วนอื่น 🙌 ทั้งหน้าเว็บและแชทบอทจะใช้ข้อมูลชุดนี้โดยอัตโนมัติ
