# เว็บไซต์ประชาสัมพันธ์และรับสมัครนักเรียน นักศึกษา วิทยาลัยเทคนิคชัยภูมิ

เว็บไซต์ต้นแบบ (prototype) สำหรับประชาสัมพันธ์และรับสมัครนักเรียน นักศึกษา พร้อมผู้ช่วย AI
("น้องเทคนิค") ตอบคำถามผู้สนใจสมัครเรียนแบบเรียลไทม์ พัฒนาด้วย [Next.js](https://nextjs.org)
และ [Claude API](https://www.anthropic.com/) ของ Anthropic

จัดทำเพื่อส่งประกวด **สิ่งประดิษฐ์ของคนรุ่นใหม่ ประจำปีการศึกษา 2569** ประเภทผลงานหลัก
กลุ่มปัญญาประดิษฐ์ (AI) โดยแผนกวิชาเทคโนโลยีสารสนเทศ

## เนื้อหาในเว็บไซต์

- หน้าแรก แนะนำวิทยาลัย
- สาขาวิชาที่เปิดสอน
- การรับสมัคร (คุณสมบัติ เอกสาร ขั้นตอน ปฏิทินรับสมัคร)
- ข่าวประชาสัมพันธ์
- ติดต่อเรา
- แชทบอท AI ลอยมุมขวาล่าง ตอบคำถามโดยอ้างอิงข้อมูลของวิทยาลัยเท่านั้น

> ℹ️ **ข้อมูลวิทยาลัยในเว็บไซต์นี้อ้างอิงจากเว็บไซต์จริง [www.ccollege.ac.th](https://www.ccollege.ac.th)**
> (สืบค้นเมื่อ 25 ก.ย. 2569) ได้แก่ ชื่อ ที่อยู่ เบอร์โทร อีเมล โซเชียลมีเดีย ประวัติ สาขาวิชา และข่าวประชาสัมพันธ์ล่าสุด
> ส่วน **รอบรับสมัคร/คุณสมบัติ/เอกสารการสมัคร** เว็บไซต์จริงยังไม่ได้ประกาศรายละเอียดปีการศึกษา 2569
> จึงใช้แนวทางทั่วไปตามระเบียบ สอศ. แทน (มีข้อความแจ้งเตือนสีฟ้าอยู่บนหน้า "การรับสมัคร")
> ข้อมูลทั้งหมดแก้ไขได้ที่ไฟล์เดียว [`lib/college-data.ts`](./lib/college-data.ts)
> ซึ่งเป็นทั้งข้อมูลที่แสดงบนเว็บไซต์และบริบทที่ AI แชทบอทใช้ตอบคำถาม (แก้ที่นี่ที่เดียว ข้อมูลจะตรงกันทั้งเว็บ)
> **แนะนำให้อาจารย์ตรวจทานความถูกต้องอีกครั้งก่อนใช้งานจริง** โดยเฉพาะปฏิทินรับสมัครที่วิทยาลัยจะประกาศภายหลัง

## เริ่มต้นใช้งาน (รันบนเครื่องตัวเอง)

### 1. ติดตั้ง dependencies

```bash
npm install
```

### 2. ตั้งค่า API key ของ Claude

คัดลอกไฟล์ `.env.example` เป็น `.env.local` แล้วใส่ API key ที่ได้จาก
[console.anthropic.com](https://console.anthropic.com/):

```bash
cp .env.example .env.local
```

```
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

### 3. รันเซิร์ฟเวอร์สำหรับพัฒนา/สาธิต

```bash
npm run dev
```

เปิดเบราว์เซอร์ไปที่ [http://localhost:3000](http://localhost:3000)

## การแก้ไขข้อมูลวิทยาลัยให้เป็นข้อมูลจริง

เปิดไฟล์ [`lib/college-data.ts`](./lib/college-data.ts) แล้วแก้ไข:

- `college` — ชื่อ ที่อยู่ เบอร์โทร อีเมล โซเชียลมีเดีย
- `programs` — รายชื่อสาขาวิชาที่เปิดสอนจริง
- `admission` — รอบรับสมัคร คุณสมบัติ เอกสาร ขั้นตอน
- `news` — ข่าวประชาสัมพันธ์จริงของวิทยาลัย

ไม่ต้องแก้โค้ดส่วนอื่น หน้าเว็บและแชทบอทจะใช้ข้อมูลชุดนี้โดยอัตโนมัติ

## โครงสร้างโปรเจกต์ (ส่วนสำคัญ)

```
app/
  page.tsx              หน้าแรก
  programs/page.tsx      สาขาวิชาที่เปิดสอน
  admission/page.tsx     การรับสมัคร
  news/page.tsx           ข่าวประชาสัมพันธ์
  contact/page.tsx        ติดต่อเรา
  api/chat/route.ts       API แชทบอท (เชื่อมต่อ Claude API แบบ streaming)
components/
  Navbar.tsx, Footer.tsx  ส่วนหัว/ท้ายเว็บไซต์
  ChatWidget.tsx          แชทบอทลอยมุมขวาล่าง
lib/
  college-data.ts         ข้อมูลวิทยาลัยทั้งหมด (แหล่งข้อมูลเดียว)
```

## หมายเหตุด้านความปลอดภัยและค่าใช้จ่าย

- API key ต้องเก็บไว้ในไฟล์ `.env.local` เท่านั้น (ไม่ถูกคอมมิตขึ้น git และไม่ถูกส่งไปฝั่งเบราว์เซอร์)
- แชทบอทถูกกำหนดให้ตอบเฉพาะเรื่องของวิทยาลัยตามข้อมูลใน `lib/college-data.ts` เท่านั้น
- หากต้องการนำไปใช้งานจริงกับผู้ใช้จำนวนมาก ควรพิจารณาโฮสต์บนบริการเช่น Vercel และเพิ่มการจำกัดจำนวนคำขอ (rate limit)
  เพื่อควบคุมค่าใช้จ่ายการเรียก API
