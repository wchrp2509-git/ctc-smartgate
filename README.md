> 🔵⚪ อดทน ขยัน มีระเบียบวินัย คุณธรรมนำวิชาชีพ — สีประจำวิทยาลัยเทคนิคชัยภูมิ

เว็บไซต์ต้นแบบ (prototype) สำหรับประชาสัมพันธ์และรับสมัครนักเรียน นักศึกษา วิทยาลัยเทคนิคชัยภูมิ
พร้อมผู้ช่วย AI **"น้องเทคนิค" 🤖** ที่คอยตอบคำถามผู้สนใจสมัครเรียนแบบเรียลไทม์ (streaming)

จัดทำโดย **แผนกวิชาเทคโนโลยีสารสนเทศ วิทยาลัยเทคนิคชัยภูมิ** เพื่อส่งเข้าประกวด
**🏆 สิ่งประดิษฐ์ของคนรุ่นใหม่ ประจำปีการศึกษา 2569** ประเภทผลงานหลัก กลุ่ม **ปัญญาประดิษฐ์ (AI)**

โจทย์ของโปรเจกต์คือการนำ AI มาช่วยแก้ปัญหาจริงของวิทยาลัย นั่นคือการ **ประชาสัมพันธ์และตอบคำถามผู้สนใจสมัครเรียน**
ที่ปกติต้องพึ่งเจ้าหน้าที่งานทะเบียนตอบคำถามซ้ำ ๆ ทีละคน เว็บไซต์นี้จึงรวมทั้ง

- 🖥️ เว็บไซต์ประชาสัมพันธ์ที่ให้ข้อมูลครบในที่เดียว (สาขาวิชา / การรับสมัคร / ข่าวสาร / ติดต่อ)

## 🧰 เทคโนโลยีที่ใช้

- ⚛️ **[Next.js 16](https://nextjs.org)** (App Router + Turbopack) — เฟรมเวิร์กหลักของเว็บไซต์

- 🎨 **Tailwind CSS v4** — จัดหน้าตาเว็บโทนน้ำเงิน-ขาวทันสมัย
- 🧠 **[Claude API](https://www.anthropic.com/) (Anthropic)** — สมองของแชทบอท "น้องเทคนิค" (สตรีมคำตอบแบบเรียลไทม์)
- 🐳 **Docker / Docker Compose** — รันเว็บไซต์เป็น container ได้ในคำสั่งเดียว

## ℹ️ ที่มาของข้อมูลวิทยาลัย

ข้อมูลวิทยาลัยในเว็บไซต์นี้อ้างอิงจากเว็บไซต์จริง **[www.ccollege.ac.th](https://www.ccollege.ac.th)**
(สืบค้นเมื่อ 25 ก.ย. 2569) ได้แก่ ชื่อ ที่อยู่ เบอร์โทร อีเมล โซเชียลมีเดีย ประวัติ สาขาวิชา และข่าวประชาสัมพันธ์ล่าสุด

⚠️ ส่วน **รอบรับสมัคร / คุณสมบัติ / เอกสารการสมัคร** เว็บไซต์จริงยังไม่ได้ประกาศรายละเอียดสำหรับปีการศึกษา 2569
จึงใช้แนวทางทั่วไปตามระเบียบสำนักงานคณะกรรมการการอาชีวศึกษา (สอศ.) แทนไปก่อน
(มีข้อความแจ้งเตือน ℹ️ สีฟ้ากำกับไว้บนหน้า "การรับสมัคร" ของเว็บไซต์)

**แนะนำให้อาจารย์ตรวจทานความถูกต้องอีกครั้งก่อนใช้งานจริง** โดยเฉพาะปฏิทินรับสมัครที่วิทยาลัยจะประกาศภายหลัง

## 🚀 เริ่มต้นใช้งาน

เลือกได้ 2 วิธี ตามความสะดวก 👇

### วิธีที่ 1 — รันบนเครื่องโดยตรง (npm)

**1. ติดตั้ง dependencies**

```bash
npm install
```

**2. ตั้งค่า API key ของ Claude**

คัดลอกไฟล์ `.env.example` เป็น `.env.local` แล้วใส่ API key ที่ได้จาก
[console.anthropic.com](https://console.anthropic.com/):

```bash
cp .env.example .env.local
```

```
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

**3. รันเซิร์ฟเวอร์สำหรับพัฒนา/สาธิต**

```bash
npm run dev
```

เปิดเบราว์เซอร์ไปที่ [http://localhost:3000](http://localhost:3000) 🎉

### วิธีที่ 2 — รันด้วย 🐳 Docker

ต้องติดตั้ง [Docker Desktop](https://www.docker.com/products/docker-desktop/) ก่อน จากนั้น:

```bash
cp .env.example .env.local   # ใส่ ANTHROPIC_API_KEY ให้เรียบร้อยก่อน
docker compose up --build -d
```

เปิดเบราว์เซอร์ไปที่ [http://localhost:3000](http://localhost:3000) — คำสั่งที่ใช้บ่อย:

```bash
docker compose logs -f web     # ดู log แบบเรียลไทม์
docker compose down            # หยุดและลบ container
```

> หากแก้ไข `.env.local` ต้องรัน `docker compose up --build -d` ใหม่ เพื่อให้ container อ่านค่าล่าสุด

## ✏️ การแก้ไขข้อมูลวิทยาลัยให้เป็นข้อมูลจริง

เปิดไฟล์ [`lib/college-data.ts`](./lib/college-data.ts) แล้วแก้ไขส่วนที่ต้องการ:

| ตัวแปร | แก้ไขอะไร |
|---|---|
| `college` | ชื่อ ที่อยู่ เบอร์โทร อีเมล โซเชียลมีเดีย |
| `programs` | รายชื่อสาขาวิชาที่เปิดสอนจริง |
| `admission` | รอบรับสมัคร คุณสมบัติ เอกสาร ขั้นตอน |
| `news` | ข่าวประชาสัมพันธ์จริงของวิทยาลัย |

ไม่ต้องแก้โค้ดส่วนอื่น 🙌 ทั้งหน้าเว็บและแชทบอทจะใช้ข้อมูลชุดนี้โดยอัตโนมัติ
